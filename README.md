# Dynamic Polling System

This project is a real-time classroom feedback system with three distinct components:

1.  **Backend (FastAPI):** Manages authentication, complex hybrid poll structures, and real-time WebSocket broadcasting.
2.  **Instructor App (Flutter Mobile):** For instructors to create hybrid polls, generate QR codes, and view live analytics.
3.  **Student Client (Flutter Web):** Students access this via a URL or QR code to submit anonymous responses.
